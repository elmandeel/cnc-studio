Educational simulation: G00 is noncutting travel; G01 linear interpolation and G02/G03 XY-plane arcs remove material using flat tool diameter and tool-tip depth. Supports G20/G21, G90/G91, modal axes, and T/M/S/F words. M98/M99 subprogram execution (including packed repetition P values), G02/G03 arcs, and linear/arc G41/G42 approximations are available. M6 changes tools without inserting a virtual Z movement; G43 tool-length tables, true chamfer-tool solid geometry, controller-specific canned-cycle behavior, machine collisions, stock fixtures, and controller-specific logic are not verified. Tool paths are interpreted, not safe to run on a real CNC without verification.
